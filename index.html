About StarNet

StarNet is a specialized cybersecurity technology company that builds automated, high-tech systems for protecting web applications and API ecosystems. Our mission is to make top-tier digital security accessible, highly accurate and easy to integrate.

In an era of rapidly growing digital threats, we believe proactive protection should not require complicated corporate bureaucracy. Through our flagship security platforms, including VMAXweb, StarNet provides deep vulnerability analysis, continuous monitoring of the attack surface and clear remediation instructions for businesses and developers worldwide.

For StarNet, cybersecurity is not a single feature. It is our foundation. We build infrastructure that protects digital trust.

  2. Continuous monitoring

  3. Clear fixes

VMAXweb

Web & API security scanner

Enter the address of a website or API and VMAXweb's asynchronous Python (FastAPI) engine runs real-time tests across six security areas. Results arrive as a Security Health Score, an interactive findings table and a downloadable PDF audit report.

Open VMAXweb↗
  • 01

    HTTP security headers

    Checks HSTS, CSP, X-Frame-Options, X-Content-Type-Options and Referrer-Policy, and flags server version leakage.

  • 02

    SSL/TLS and transport

    Certificate validity, issuer and expiry, plus HTTP to HTTPS redirect enforcement.

  • 03

    API and endpoint audit

    CORS misconfiguration and risky HTTP methods such as PUT, DELETE, TRACE and OPTIONS.

  • 04

    Sensitive data exposure

    Publicly reachable files like /.env, /.git/, /config.json, /swagger.json and /backup.zip, and cookie Secure, HttpOnly and SameSite flags.

  • 05

    Network and port security

    Common high-risk ports: SSH 22, MySQL 3306, PostgreSQL 5432, Redis 6379, MongoDB 27017, and 8080/8443.

  • 06

    Subdomain mapping

    Discovers linked subdomains such as dev and admin, where forgotten test versions often stay exposed.
